Network Routing Methods

Routing determines how packets move from one network to another. Routers examine their routing tables and select an appropriate path toward each destination.

Routing Fundamentals

How Routers Learn and Select Routes

A router can learn routes from its connected interfaces, manual configuration, or dynamic routing protocols. These routes are stored in a routing table and used to forward packets toward their destinations.

1. How a Router Obtains Routes

Routes can enter the routing table through connected networks, static configuration, or dynamic routing protocols.

Route Learning How a route enters the routing table
Directly Connected Created when an active router interface has an assigned IP network
Connected Route No next-hop router is required
Static Routing Routes manually configured by an administrator
Specific Static Route
Static Default Route 0.0.0.0/0
Dynamic Routing Routes automatically learned through routing protocols
Specific Learned Routes
Learned Default Route

Technical note: A default route is not a completely separate route-learning method. It can be manually configured or dynamically learned.

2. Dynamic Routing Protocols by Algorithm

Dynamic routing protocols can be classified according to how they exchange information and calculate preferred routes.

Dynamic Routing Protocols Automatically exchange and update routing information
Distance-Vector Shares route information with neighboring routers
RIP Hop-count metric
IGRP Legacy and obsolete
Link-State Builds a topology map and calculates shortest paths
OSPF Cost metric
IS-IS Cost metric
Advanced Distance-Vector Commonly described as a hybrid approach
EIGRP Composite metric
Path-Vector Selects routes using policy and path attributes
BGP Attributes and AS path
