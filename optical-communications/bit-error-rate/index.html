What Is Bit Error Rate?

Bit Error Rate, or BER, measures how reliably a digital communication system transfers data from a transmitter to a receiver.

A bit error occurs when the receiver detects a different bit from the one that was transmitted.

BER = Number of Erroneous Bits Total Number of Tested Bits

Transmitted: 1 0 1 1 0 0 1 0
Received: 1 0 1 0 0 0 1 0

The highlighted bit is incorrect: the transmitter sent 1, but the receiver detected 0.
