BER Fundamentals

What Is Bit Error Rate?

Bit Error Rate, or BER, measures how reliably a digital communication system transfers data from a transmitter to a receiver.

A bit error occurs when the receiver detects a different bit from the one that was transmitted.

BER = Number of Erroneous Bits Total Number of Tested Bits

Transmitted: 1 0 1 1 0 0 1 0
Received: 1 0 1 0 0 0 1 0

The highlighted bit is incorrect: the transmitter sent 1, but the receiver detected 0.

BER Interpretation

What Do BER Values Mean?

BER is usually written using scientific notation. Smaller BER values indicate better communication performance.

BER Approximate Meaning
10-3 About 1 error in every 1,000 bits
10-6 About 1 error in every 1 million bits
10-9 About 1 error in every 1 billion bits
10-12 About 1 error in every 1 trillion bits
BER Testing

How Is BER Measured?

In an optical communication system, a known digital bit pattern is transmitted through the optical link. The received bits are then compared with the transmitted bits to determine how many errors occurred.

Signal Impairments

What Causes Bit Errors?

Bit errors occur when the received signal becomes distorted, weakened, or noisy enough that the receiver makes an incorrect decision between a digital 1 and 0.

P↓

Low Received Power

As received optical power decreases, the signal becomes more difficult to distinguish from receiver noise.

N

Noise

Electrical and optical noise can disturb the received signal and cause incorrect bit decisions.

Δt

Jitter

Timing variations can move the signal transitions away from their ideal positions and reduce timing margin.

D

Dispersion

Dispersion broadens optical pulses as they travel through the fiber, causing neighboring bits to overlap.

XT

Crosstalk

Unwanted coupling from another channel can interfere with the desired signal and increase the probability of errors.

↩

Reflections

Optical reflections from connectors, interfaces, or other discontinuities can disturb the transmitted signal.

BER Statistics

What Does Confidence Level Mean?

Observing zero errors during a BER test does not mean that the BER is zero. Errors may simply be rare enough that none occurred during the test.

The confidence level tells us how much statistical evidence a zero-error test provides that the link performs better than the specified BER target.

1. Start with the BER target

Suppose the required BER is:

BERtarget = 10−12

This corresponds to an error probability of approximately one error per trillion transmitted bits.

2. Probability of observing zero errors

If the probability of a bit error is p, then the probability that one bit contains no error is:

1 − p

If N independent bits are tested, the probability of observing zero errors is:

P(0 errors) = (1 − p)N

3. Introduce the confidence level

For a 95% confidence test:

C = 0.95

The remaining probability is:

1 − C = 0.05

We therefore choose the number of tested bits so that, if the true BER were exactly equal to the BER target, the probability of observing zero errors would be only 5%.

(1 − p)N = 1 − C

4. Solve for the required number of bits

For very small BER values, the zero-error relationship can be approximated as:

N ≈ −ln(1 − C) BERtarget

5. Example: 95% confidence

For a confidence level of 95%:

−ln(1 − 0.95) = −ln(0.05) ≈ 3

Therefore, for a BER target of 10−12:

N ≈ 3 10−12 = 3 × 1012 bits

BER Target: 10−12 ↓ Confidence: 95% ↓ Required Bits: ≈ 3 × 1012
BER Test Duration

How Long Should a BER Test Run?

Once the required number of tested bits is known, the test duration depends on the data rate of the link.

t = N R

where:

t = required test time, N = required number of tested bits, and R = data rate in bits per second.

Example: 95% Confidence at 100 Gb/s

For a BER target of 10−12 at 95% confidence, we previously found:

N ≈ 3 × 1012 bits

The data rate is:

R = 100 × 109 bits/s

Therefore:

t = 3 × 1012 100 × 109 = 30 s

BER Target: 10−12 ↓ Confidence: 95% ↓ Required Bits: ≈ 3 × 1012 ↓ Data Rate: 100 Gb/s ↓ Test Time: ≈ 30 seconds
