Introduction

What Is Routing?

Routing is the process of selecting a path for an IP packet from its source network to its destination network.

A router examines the destination IP address in each packet, searches its routing table, selects the best matching route, and forwards the packet through the appropriate interface or next-hop router.

Basic routing process Destination IP address → routing-table lookup → best route → outgoing interface or next hop
Network Layer

Where Does IPv4 Fit?

IPv4 addressing and routing operate primarily at Layer 3, the network layer of the OSI model.

L1

Physical Layer

Optical fibers, free-space optical links, lasers, photodetectors, transceivers, connectors, and signals.

L2

Data-Link Layer

Ethernet frames, MAC addresses, switching, error detection, and communication over a local link.

L3

Network Layer

IPv4 and IPv6 addressing, routers, routing tables, path selection, and packet forwarding.

Route Learning

How Each Method Works

Each method offers a different balance of simplicity, scalability, control, and automatic adaptation.

C

Directly Connected Route

The router creates this route automatically when an interface is configured, active, and connected to a network.

S

Static Route

The administrator manually defines the destination network, subnet mask or prefix, and next hop or exit interface.

0

Default Route

The router uses this route when the routing table contains no more-specific match. In IPv4, it is written as 0.0.0.0/0.

D

Dynamic Route

Routers exchange network information and automatically update routes when network conditions or topology change.

Dynamic routing protocols can be classified by how they exchange information and calculate the best path.

Comparison

Routing-Method Summary

The correct routing method depends on network size, complexity, reliability requirements, and expected changes.

Method How It Is Learned Primary Advantage Primary Limitation Typical Use
Directly Connected Created automatically from active interfaces Immediate and simple Reaches only attached networks Every routed network
Static Configured manually Predictable and controlled Does not adapt automatically Small or stable networks
Default Usually configured manually Reduces routing-table complexity May not provide the best path Internet or upstream gateway access
Dynamic Learned through routing protocols Adapts to topology changes Requires processing and configuration Medium and large networks
System Perspective

Routing in Optical Networks

Optical communication provides the physical transmission paths, while routing determines which sequence of links carries the network traffic.

Physical path versus logical route A fiber or optical inter-satellite link provides Layer 1 connectivity. Ethernet operates at Layer 2, while IPv4 and routing protocols select paths at Layer 3. A network route can therefore traverse several individual optical links.
